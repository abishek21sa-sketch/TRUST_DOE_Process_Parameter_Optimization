# Claim Ledger

Every surfaced result must be tagged as one of: REAL OBSERVED DATA, DERIVED ANALYSIS, MODEL PREDICTION, SIMULATION RESULT, OPTIMIZATION RESULT, REFERENCE/SYNTHETIC TEST, or ASSUMPTION.

## Project boundary
Published NIST process-development evidence; not an experiment run by this repository or a private plant.

## Human authority
Final operational execution authority: `PROCESS_DEVELOPMENT_ENGINEER`. The analytical agent may investigate, predict, simulate, optimize, challenge, recommend, or HOLD; it does not autonomously execute the operational action.
